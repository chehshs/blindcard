# Web アプリ本体。本番サーバーにはこれだけ入れれば動きます。
#
# Flask 3.x は Python 3.8 以上が必要です。共有サーバーが 3.7 の場合に
# 「満たすバージョンが無い」で止まらないよう、条件を分けています。
flask>=3.0 ; python_version >= "3.8"
flask>=2.2,<3 ; python_version < "3.8"
#
# reportlab 4.4.2 以降は f文字列の = 指定（3.8以降の構文）を含むのに、
# パッケージ側の申告は「3.7 以上」のままです。3.7 の環境では pip がそのまま
# 入れてしまい、import した瞬間に SyntaxError で落ちます。
# 3.7 では 4.3 系までに抑えます。
reportlab>=4.0 ; python_version >= "3.8"
reportlab>=4.0,<4.4 ; python_version < "3.8"
