手入力でもCSVでも

表に直接書くか、Excel / スプレッドシートから書き出したCSVを読み込めます。

プレビューしてからPDF

1ページ目の見え方を確認してから書き出せます。一度に2000件まで。

赤シートで隠せる

解答は標準のオレンジなどの色で印字します。カラー印刷してシートを重ねると、問題だけが残ります。

基本の流れ

  1. 1

    問題を入れる

    「行追加」で1問ずつ書くか、「CSVを読み込む」でまとめて取り込みます。表の上にCSVをドロップしても読み込めます。

  2. 2

    用紙と見た目を選ぶ

    左のプリント設定で用紙サイズ、行数、タイトル、番号の表記、解答色を決めます。狭い画面では左上のメニューから開けます。

  3. 3

    プレビューで確認する

    右上の「プレビュー」で1ページ目のレイアウトを見ます。問題か解答が1件以上あると使えます。

  4. 4

    PDFを発行して印刷する

    「PDFを発行する」でダウンロードされます。赤シートで使うときはカラー印刷してください。

問題の入れ方

列 画面上の名前 印刷される場所
1 No. 問題の左上の番号
2 Question 左半分（黒）
3 Answer 右半分（解答色）
4 Notes 解答の下（任意）
  • 「行追加」で末尾に1行足します。番号は直前の行から自動で続きを付けます。
  • 「CSV保存」で今の表をUTF-8のCSVとして書き出せます。あとから同じファイルを読み込めます。
  • 「クリア」は表の中身をすべて消します。元には戻せません。

CSVの書き方

4列です。1行目が見出しなら自動で読み飛ばします。

番号,問題,解答,備考
1-1,絶好のキカイ,機会,[類]好機
1-2,宇宙のシンリ,真理,
2-1,植物のヨウブン,養分,

見出しとして認識される語

番号 / 問題 / 解答 / 備考、または num / question / answer / note

文字コード

UTF-8（ExcelのBOM付きも可）と Shift_JIS の両方に対応しています。

見出しが「番号ID」「例文」のような独自の名前だと、1行目もデータとして取り込まれます。表で直せば問題ありません。

プリント設定

用紙サイズ

A6（105×148 mm）が標準です。A5・A4は同じレイアウトを拡大します。

1ページの行数

3 / 5 / 8 / 10。多いほど文字は小さくなります。

ヘッダータイトル

ページ上部に「タイトル - NO.1」と出ます。空欄なら BlindCardMaker になります。80文字まで。

番号の表記

「1-1」は入力した番号のまま。「1. 2. 3.」はそのページ内の連番です。

チェック欄

番号の横に小さな四角を付けます。覚えた問題に印を付ける用途です。

解答色

赤シート用です。標準はオレンジで、赤シートに隠れやすい色です。隠れにくいときは赤に変えてください。紫はほぼ残ります。

番号とページの分かれ方

番号にハイフンがあるときだけ、ハイフンの前が「まとまり」になります。まとまりが変わると新しいページから始まります。

番号の例 動き
1-1, 1-2, 1-3 同じまとまり。空いた行を埋めて続けて印刷します。
1-5 の次が 2-1 まとまりが変わるので、2-1 から新しいページです。
1, 2, 3 … 連番は同じまとまりのまま詰めて印刷します。
番号なし 連番と同じく、ひと続きのページになります。

画面上の「記入 N 件 · 約 M ページ」は、このルールで見積もったページ数です。

赤シートの使い方

  1. 1

    カラーで印刷します。白黒だと解答が隠せません。

  2. 2

    右半分（色の付いた解答）に赤シートを重ねます。問題だけが残ります。

  3. 3

    答えたらシートをずらして答え合わせします。チェック欄を付けていれば、覚えた問題に印を付けられます。

うまくいかないとき

PDFを発行するボタンが押せない

問題または解答が1件以上必要です。番号だけの行では書き出せません。

CSVの1行目が消えた

見出し行と判定されると読み飛ばされます。1列目に数字がある行はデータとして残します。

ページが分かれすぎる

1-1 と 2-1 のようにハイフンの前が変わると、そこで改ページします。続けて印刷したいときは連番にするか、同じ接頭辞にしてください。

長い文が途中で切れる

1行に収まるよう文字を小さくし、それでも入らなければ末尾を省略します。行数を減らすと入りやすくなります。

2000件を超えると言われる

一度に出力できる上限です。CSVを分割して複数回書き出してください。
